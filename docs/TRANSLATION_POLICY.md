- 결정일: 2026-10-03
- 결정자: 저장소 소유자(사용자)
- 결정: **A안 — 한국어 번역을 공개 저장소와 GitHub Pages 배포물에 포함한다.**
- 상태: 확정. 이 문서가 `docs/GOAL.md` §5·§8의 "번역 결과물 배포 금지" 조항을 대체한다.

## 배경: 두 문서가 충돌했다

| 문서 | 내용 |
|---|---|
| `docs/GOAL.md` §5·§8 (초기 인수인계 문서) | 번역문은 원문의 2차적저작물이므로 배포가 곤란하다. 저장소에는 번역 테이블 **생성 스크립트만** 두고, 결과물은 사용자의 게임 데이터에서 로컬로 생성한다. |
| `.omo/plans/ultima-web.md` Must have 5·10 (2026-09-07 결정) | 한국어 번역을 사전에 전부 작성해 **정적 배포물에 포함**한다. 한국어 번역 원천 JSON은 공개한다. |

구현은 계획서를 따랐다. 그래서 2026-10-03 시점에 `locales/ko/tlk.json`(NPC 대사 번역 약 3천 항목), `locales/ko/binary.json`(TITLE.EXE·AVATAR.EXE 표시 문자열 번역)이 public 저장소에 커밋돼 있고, 생성 테이블을 통해 Pages 배포물에도 들어 있다.

## 검토한 선택지

| 안 | 내용 | 결과 |
|---|---|---|
| **A. 현재 유지 (번역 공개)** | `docs/GOAL.md`를 계획서에 맞춘다 | **채택** |
| B. 비공개 번역 팩 | 번역 JSON을 저장소·배포물에서 빼고 사용자가 원본 ZIP처럼 직접 선택 | 기각 — 배포 경로 문제가 다시 생기고, 이미 공개된 git 히스토리는 회수 불가 |
| C. 원문 의존 패치(diff) 배포 | 원본이 있어야만 번역이 복원되는 형태 | 기각 — 구현 비용 큼, 법적 안전성 보장도 없음 |
| D. NPC 대사 한국어 포기 | TLK 대사만 영어 유지 | 기각 — 한글화의 핵심 가치 상실 |

채택 이유: 비상업 개인 팬 번역 프로젝트이고, 번역은 이미 공개 히스토리에 있어 되돌려도 실효가 제한적이며, 사용자 경험(ZIP 하나만 선택하면 한국어 플레이)이 가장 좋다. 법률 검토를 거친 결정은 아니다.

## 이 결정으로 바뀌지 않는 것 (계속 금지)

- 원본 게임 데이터 커밋·배포: `ultima4.zip`, 원본 `.EXE`·`.TLK`·`.MAP`·`.EGA`·`.SAV`.
- **영어 원문 corpus** 커밋·배포: 번역 JSON은 원문 대신 `sourceHash`(SHA-256)만 가진다. 이 구조를 유지한다. 새 번역 항목을 추가할 때도 영어 원문을 JSON·생성 테이블·로그·evidence에 넣지 않는다.
- 엔진이 TLK·바이너리 원문을 JS로 내보내는 경로: 계속 id(`MAP:npcIndex:field`, `resource:table:index`)로만 보낸다.
- `npm run audit:dist`의 원본 데이터 유출 검사는 그대로 강제한다.

## 이 결정으로 해야 하는 것

1. `docs/GOAL.md` §5·§8을 이 결정에 맞게 고친다 (완료, 2026-10-03).
2. `README.md`에 고지를 둔다: 비공식 팬 번역이며 권리자(EA 등)와 무관하다, 원본 데이터는 포함하지 않는다, 권리자 요청 시 번역을 내린다 (완료, 2026-10-03).
3. 권리자 요청(삭제 요청)이 오면: `locales/ko/tlk.json`·`binary.json`의 번역을 비우고 생성 테이블을 재생성해 배포한 뒤, 이 문서에 날짜와 조치를 기록한다. 이때 B안(비공개 번역 팩)이 다음 후보다.
