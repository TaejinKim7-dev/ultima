개인정보 처리방침

시행일: 2026년 10월 6일 · 대상: Ultima IV 웹 한글판(https://taejinkim7-dev.github.io/ultima/, 이하 "이 사이트")

1. 이 사이트가 하는 일

이 사이트는 비상업 팬 프로젝트로, 플레이어가 직접 가진 Ultima IV 원본 데이터(ultima4.zip)를 브라우저에서 실행해 한국어로 보여 주는 정적 웹 페이지입니다. 운영자는 서버를 두지 않으며, 플레이어의 데이터를 운영자에게 보내는 기능이 없습니다.

2. 브라우저 안에만 저장되는 정보

  • 플레이어가 고른 원본 ultima4.zip: 다음 방문 때 다시 고르지 않도록 이 브라우저의 저장소(IndexedDB)에만 보관합니다. 어디에도 업로드하지 않으며, "저장된 원본 지우기" 버튼으로 지울 수 있습니다.
  • 게임 저장 파일과 저장 슬롯, 게임 설정: 이 브라우저의 저장소에만 보관합니다.
  • 문제 확인용 기록: 브라우저 메모리에만 잠시 남고 페이지를 닫으면 사라지며, 운영자에게 전송되지 않습니다.

브라우저의 사이트 데이터를 지우면 위 정보는 모두 삭제됩니다.

3. Google Drive 연결(선택 기능)

플레이어가 "Google Drive 연결"을 직접 누른 경우에만 동작합니다.

  • 요청하는 권한: drive.appdata 하나뿐입니다. 이 권한으로는 이 앱이 만든 숨김 앱 폴더의 파일만 읽고 쓸 수 있으며, 플레이어의 다른 Google Drive 파일은 볼 수도 바꿀 수도 없습니다.
  • 저장되는 내용: 저장 슬롯 파일(게임 진행 상태, 슬롯 이름, 저장 시각)만 플레이어 본인의 Google Drive에 저장됩니다. 원본 게임 데이터는 올리지 않습니다.
  • 운영자의 접근: 운영자는 플레이어의 Drive나 저장 파일에 접근할 수 없습니다. 파일은 브라우저와 Google 사이에서만 오갑니다.
  • 로그인 정보: Google이 발급한 접근 토큰은 브라우저 메모리에만 두고 저장하지 않으며, 페이지를 닫거나 "연결 해제"를 누르면 사라집니다. 이 사이트는 플레이어의 이메일이나 이름 같은 계정 정보를 요청하지 않습니다.
  • 삭제와 해제: "연결 해제"로 연결을 끊을 수 있고, Google 계정 설정의 "보안 → 타사 앱 및 서비스"에서 이 앱의 권한을 언제든 취소할 수 있습니다. 권한을 취소하면 앱 폴더의 데이터는 Google 정책에 따라 플레이어가 Drive 설정에서 삭제할 수 있습니다.

Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. 받은 데이터는 저장 슬롯을 동기화하는 목적 외에는 쓰지 않으며, 다른 사람에게 넘기거나 광고에 쓰지 않습니다.

4. 쿠키와 분석 도구

이 사이트는 광고, 분석, 추적 도구를 쓰지 않습니다. 호스팅은 GitHub Pages가 하며, GitHub는 서비스 운영을 위해 접속 기록을 남길 수 있습니다(GitHub의 개인정보 처리방침을 따릅니다).

Privacy Policy (English summary)

Ultima IV Web (Korean) is a non-commercial fan project served as static pages from GitHub Pages; the operator runs no server. The player's own original game data, save files, save slots and settings stay in the player's browser (IndexedDB) and are never uploaded. The optional Google Drive feature runs only when the player clicks "Google Drive 연결", requests only the drive.appdata scope, and stores save-slot files only in the player's own Drive app-data folder; it cannot see any other Drive file, does not request profile or email information, and the operator has no access to the player's Drive. The access token is kept in memory only. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements; data is used only to sync the player's save slots and is never shared or used for advertising. No analytics, ads or tracking. Contact: Issues of the GitHub repository TaejinKim7-dev/ultima.
